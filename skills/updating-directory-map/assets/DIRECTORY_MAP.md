# Directory Map

## Root Directories

- `directory/`: 负责什么；必要时补一句该目录存在的原因
- `another-directory/`: 负责什么；不写实现细节或子文件清单

## Important Files

- `path/to/file`: 为什么这个文件是入口、共享契约或全局配置
- `path/to/another-file`: 为什么未来 agent 应优先知道它

## Module Responsibilities

- `path/to/module/`: 负责什么；不负责什么
- `path/to/another-module/`: 负责什么；不应放入什么类型的代码

## Forbidden Contents By Directory

- `path/to/directory/`: 不应包含什么，以及原因
- `path/to/another-directory/`: 不应包含什么边界外内容
